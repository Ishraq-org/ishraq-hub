🧠 Observation: Telegram Bot Philosophy This is what I would add to the Claude prompt. Telegram Bot is NOT another website The Telegram Bot is not a miniature version of the website. It is not intended to duplicate every feature available on the web platform. Instead, it serves as a companion that complements the website by providing quick access, notifications, and daily engagement. The website remains the primary destination for deep learning, structured research, article reading, courses, and resource management. The Telegram Bot focuses on speed, convenience, and user engagement. Platform Responsibilities 🌐 Website The website is the Knowledge Hub. It is responsible for: Reading research articles Browsing topics and subtopics Downloading resources Enrolling in courses Managing personal dashboard Bookmarking content Advanced search Contributor workflows Administration 🤖 Telegram Bot The Telegram Bot is the Knowledge Companion. Its purpose is to help users interact with the Ishraq platform quickly without replacing the website. Shared Infrastructure The website and Telegram Bot must never maintain separate databases. Both platforms share: One Backend API One MongoDB Atlas database One authentication system One user profile One bookmark system One course progress system One notification system The Telegram Bot communicates only with the backend API. It never communicates directly with MongoDB. This keeps business logic centralized and ensures consistency across platforms. Core Telegram Features Rather than duplicating the website, the Telegram Bot should provide features that are naturally suited to a messaging platform. Examples include: 🔍 Quick Knowledge Search Users can instantly search the Ishraq knowledge base using simple commands. Example: /search Trinity The bot returns: Related Articles Related Debates Related Resources with direct links to the website. 📚 Resource Finder Users can request books, PDFs, or other study materials without navigating the website. Example: /resource Quran Manuscripts 🔔 Personalized Notifications The bot should notify users when: New articles are published New resources are uploaded New courses become available Bookmarked content is updated (optional) 📖 Reading Reminders If a user bookmarks or starts reading an article on the website but does not finish it, the bot can send a reminder after a configurable period. 🎓 Course Companion When courses are introduced, the bot should support learning by: reminding users about unfinished lessons, announcing new lessons, linking directly to the course page. The actual course experience remains on the website. 📅 Daily Knowledge The bot can deliver scheduled educational content such as: Today's Article Today's Quran Reflection Today's Hadith Weekly Recommended Reading These messages should always link back to the website for deeper study. 👤 Personal Account Summary Users can quickly check: Saved articles Bookmarks Course progress Recently viewed content without opening the website. Features the Telegram Bot Should NOT Replace To preserve the website as the primary platform, the Telegram Bot should not attempt to replicate: Full article reading Complete debate pages Article editing Resource management Administration Rich formatting Complex navigation Instead, it should always redirect users to the website when a richer interface is needed. Design Principle One Brain, Two Experiences. The website and Telegram Bot are two interfaces built on top of the same backend. They share the same knowledge and user data, but each platform is optimized for its own strengths. The website provides depth. The Telegram Bot provides speed and engagement.
