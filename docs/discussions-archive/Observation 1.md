My biggest observation
This isn't a website anymore.
It isn't even just a "web system."
It's becoming a Digital Knowledge Platform.
That's an important distinction.
Because if we keep thinking:

"Let's build pages."

We'll eventually paint ourselves into a corner.
Instead, we should think:

"Let's build an ecosystem."

From everything you've written, I don't see "articles" as the center anymore.
I see this:

                 ISHRAQ

      Knowledge
          |
-----------------------------

Everything revolves around knowledge.

Courses are another.

That changes the architecture.

Tenth observation
The multilingual idea.
This is where I think we should be careful.
Don't think:

Amharic

↓

Translate

↓

English

Internally, think:

Knowledge Item

├── Amharic

├── English

└── Future languages

Your database should treat languages as parallel versions of the same knowledge item, not as a "main" language and a translated copy. That gives you more flexibility if one language is updated before another.

Overall
I think you're no longer designing a website.
You're designing something closer to a Knowledge Management System (KMS) tailored for Islamic apologetics and education.
That changes how we should approach everything—from the database schema to the admin dashboard to the search experience.

I'd define Ishraq as something like:

"Ishraq is a digital Islamic Knowledge Platform designed to organize, preserve, teach, and interconnect authentic Islamic apologetics knowledge through research articles, educational courses, structured resources, and modern learning experiences."
