```
/api
├── /auth
│   ├── /register
│   ├── /login
│   └── /logout
│
├── /users
│   ├── /profile
│   ├── /settings
│   └── /bookmarks
│
├── /articles
│   ├── / (list)
│   ├── /:slug
│   ├── /:slug/related
│   └── /search
│
├── /resources
│   ├── / (list)
│   ├── /:id
│   └── /download/:id
│
├── /courses
│   ├── / (list)
│   ├── /:slug
│   └── /:slug/progress
│
├── /quran (future)
│   ├── /surahs
│   ├── /surah/:id
│   ├── /ayah/:id
│   └── /search
│
├── /community (future)
│   ├── /posts
│   ├── /topics
│   └── /comments
│
└── /admin
    ├── /users
    ├── /content
    └── /settings
```

### Database Collections (Shared)

```
Collections:
├── users
├── articles
├── topics
├── resources
├── courses
├── enrollments
├── bookmarks
├── progress
├── quran_verses (future)
├── quran_translations (future)
├── hadith (future)
├── community_posts (future)
├── community_comments (future)

```

### Authentication (Universal SSO)

```
One Account = All Platforms

User logs into:
├── Website → Token generated
├── Mobile App → Same token works
├── Telegram Bot → Linked via token
├── Quran App → Same token works
└── Learning Platform → Same token works

Benefits:
├── ✅ Seamless experience
├── ✅ No multiple accounts
├── ✅ Consistent profile
├── ✅ Shared bookmarks
├── ✅ Unified progress
└── ✅ Easy to use
```
