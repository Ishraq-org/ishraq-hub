Fallback: reading in Amharic with no published AM translation → serve English with a "translation coming soon" banner, not a 404. Chosen over the single-document/embedded-fields model to support independent EN/AM publish timing, a clean home for a future Translator role, and painless addition of Oromo/Tigrinya/Somali later without schema explosion. | Claude discussion, 2026-08-06 |
| **Footnotes & citations** | Inline TipTap node carrying its own citation content (not a marker into a separately-maintained list). | **V1 active roles** | Simplified to **three roles**: `Member` (basic reader account — sign up to bookmark/save, no content rights), `Contributor` (create/submit content for review), `Super Admin` (review, publish, edit anything, archive). The separate `Admin` tier from the original 7-role plan is **dropped for v1** — no rank exists between Contributor and Super Admin. Author/Reviewer/Moderator remain future-only, unactivated. | Claude discussion, 2026-08-06 |
| **Article workflow states** | Five states: `draft → in_review → published`, with `changes_requested` as a branch off `in_review` (distinct from `draft` so the Contributor sees admin feedback rather than an empty restart), and `published ⇄ archived` (reversible, Super Admin only). Contributor: create/edit own draft, submit to review, edit+resubmit from `changes_requested`. Super Admin: approve/send-back reviews, archive/unarchive, edit anyone's content directly, **self-publish own writing** (`draft → published` with no forced review, since no rank sits above Super Admin) — cross-review between Super Admins stays informal/optional, not system-enforced. A Contributor can never directly edit already-published content — fixes/improvements go through a new `in_review` cycle to protect published accuracy. | Claude discussion, 2026-08-06 |
